# 実店舗集客コンサルティング LP（料金プラン追加版）

既存のLPを修正しました。写真6素材、配色、メインコピー、プロフィールを保持。外部公開・決済・フォーム送信は行っていません。

## Macでの確認

ZIPを展開し、`lp-preview.html` をChromeまたはSafariで開いてください。写真・CSS・JavaScriptを内蔵しているので、1ファイルで確認できます。
`source/index.html` は編集・公開用です。同じフォルダのCSS・JS・assetsと一緒に使用します。

## 変更する場所

- `source/config.js`：各プランの料金、相談時間、提供開始時期、レポート納期、申込URL、質問サポート条件、予約方法、各規定URL、受付開始フラグ。
- `source/index.html`：本文・内容の一覧・プロフィール。料金と時間のHTML初期値も記載。JavaScript無効時の表示も変える場合は両方を更新してください。
- `source/style.css`：配色・レイアウト。末尾に今回の料金表用CSSを追加。
- `source/app.js`：プラン選択、受付条件、画像拡大。申込情報は保存・送信しません。
- `source/assets`：既存の画像。変更・再生成していません。

## 申込導線

各プランの「申込案内を見る」を押すと、ページ下部でそのプランが選ばれます。プランの選択だけでは申込を送信しません。
現在は受付準備中で、送信・決済リンクは表示しません。各プランの `formUrl` は空欄です。

接続時は、プランが事前入力されたフォームURL、またはプラン別の専用フォームURLを設定してください。外部フォーム側の仕様は一律でないため、LPから任意のパラメータを付ける方式は使っていません。フォーム内で希望プランを必須にし、受信結果にプラン名が残ることを確認してください。

受付開始フラグをtrueにしても、規定URL・予約方法・提供開始時期・そのプランのフォームURL等が未設定のプランは送信リンクが出ません。レポート付きは納期、実行サポートは質問対応方法・範囲・返信目安・起算日も必要です。

## 公開前の設定一覧

1. 各プランの提供開始時期。
2. 地域集客戦略・実行サポートのレポート納期（入金確認からの日数等）。
3. オンライン相談の予約方法・実施ツール。
4. 30日間の質問サポート：対応方法、相談範囲、返信目安、起算日。代行作業・成果保証は対象外。
5. 申込フォーム：氏名、メール、希望プラン、店舗名、市区町村、業種、相談内容。HP/Instagram URLは任意。
6. フォームの受信先、受付メール、同意欄、希望プランの受信確認。3プランそれぞれでテスト申込し、料金とプラン名が一致することを確認する。
7. PayPal・銀行振込の決済案内メール、入金確認と提供開始の運用。
8. キャンセル・返金・日程変更・提供中止時の取扱い。調査開始後や30日間サポート開始後の扱いも確定する。
9. 個人情報の取扱い・特定商取引法に基づく表示。販売者情報、連絡先、価格・追加費用、支払時期、提供時期、取消条件など、実際の販売形態に必要な項目を整える。
10. `acceptingApplications` をtrueにする。正式公開時は `noindex,nofollow` を変更し、公開URLに合わせcanonical・OG設定を追加する。

規定ページの内容は未確定のため、本文を創作して掲載していません。この一覧は法的充足を保証するものではありません。

## 申込み後の案内文（フォーム完了画面・受付メール用）

ご希望のプランと店舗情報を確認のうえ、ご入力いただいたメールアドレスへ、お支払い方法（PayPalまたは銀行振込）をご案内します。

入金確認後、選択されたプランの提供準備を開始します。レポート付きプランでは、オンライン相談の前に分析レポートをお渡しします。

※返信までの目安と問い合わせ先を確定して追加してください。自動送信はフォーム側で設定が必要です。
